# 🏫 LabReserve - Sistema de Agendamento de Laboratórios

O **LabReserve** é um sistema desenvolvido para automatizar e organizar o agendamento de laboratórios acadêmicos (informática, química, salas de estudo). Ele resolve o problema de superlotação e conflitos de horários em instituições de ensino, garantindo que não haja duas reservas para o mesmo ambiente no mesmo horário.

## 🚀 Tecnologias Utilizadas
* **Java 17**
* **JavaFX** (Interface Gráfica)
* **CSS3** (Estilização personalizada)

## ⚙️ Principais Funcionalidades
* **Cadastro de Entidades:** Gerenciamento de Usuários (Professores/Alunos) e Laboratórios.
* **Reserva Inteligente:** Validação de disponibilidade de horários (Regra anti-conflito).
* **Gestão de Status:** Controle do ciclo da reserva (Pendente, Em Uso, Finalizada).
* **Painel do Dia:** Visualização rápida das reservas da data atual para entrega de chaves.
